# Reverse Prompt AI — Hero Landing Page

이 폴더는 `역프롬프트 이미지 생성 AI`의 소개용 히어로 랜딩 페이지를
기존 애플리케이션과 분리하여 개발하기 위한 독립 작업 영역입니다.

## 분리 원칙

- 기존 애플리케이션 소스와 API 로직은 수정하지 않습니다.
- 히어로 페이지의 컴포넌트, 스타일, 이미지 및 설정은 이 폴더 안에서 관리합니다.
- 히어로 페이지의 `앱 시작하기` 버튼은 기존 앱 주소로 연결합니다.
- 개발과 검증은 `codex/hero-landing-page` 브랜치에서 진행합니다.
- 완성 후 검토를 거쳐야만 `main` 브랜치에 병합합니다.

## 예정 구성

```text
hero/
├─ public/          # 랜딩 페이지 이미지와 정적 리소스
├─ src/             # 화면 컴포넌트와 스타일
├─ index.html
├─ package.json
└─ README.md
```

## 배포 경로

- `/` — 히어로 랜딩 페이지
- `/app` 또는 별도 앱 URL — 기존 이미지 분석·생성 애플리케이션

> 이 문서는 작업 영역을 먼저 확정하기 위한 파일입니다. 실제 랜딩 페이지
> 구현물은 모두 이 폴더 안에 추가합니다.
